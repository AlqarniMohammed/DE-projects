# Resume

Re-entry ritual after a break, per the comeback ritual in `GUIDE.md` § "Coming back after a break": don't restart, re-enter. Momentum returns in an evening; guilt-driven restarts cost weeks.

## Procedure

1. **Read `PROGRESS.md`.** Identify:
   - the current phase: the first phase whose `**Gate G<n> passed on:**` line is still blank (respect an **Entry phase** note in the header, if any);
   - the last logged retrieval checkpoint (the "Retrieval-checkpoint log" table: date, phases sampled, score, weak terms).
2. **Step 1 — retrieval first.** Offer both, learner's pick: re-run the last logged checkpoint (the `quiz` skill on the same phases it sampled, with the logged weak terms forced into the earlier-terms sample), or a warm quiz on the current phase's terms. If no checkpoint is logged yet, offer only the current phase's quiz. If the learner declines, move on without comment.
3. **Step 2 — re-anchor.** Show the current phase's Objectives, verbatim, from `phases/phase-<n>-*/README.md`. No summary, no additions — the point is recognition, not novelty.
4. **Step 3 — three warm-ups.** `PROGRESS.md` does not record mid-phase position — ask the learner which of the phase's build steps and Learn rows are already done (one question, a rough answer is fine), then propose exactly three 30-minute tasks drawn from what remains, smallest first — the shape to aim for: a link or doc fix, a single test, a small PR. For each: what to do, where (file or README section), and what "done" looks like within 30 minutes. Ask which one to start with, and help do it.
5. **If their available hours changed over the break,** point at the `study-plan` skill — a new pace is a new forecast, never a new gate.

## Tone rules

- Momentum, zero guilt. Never mention how long the break was, never tally lost time, never suggest redoing completed work.
- Do not audit the whole tracker or enumerate everything outstanding — that is the `gate-check` skill's job, offered only if the learner asks where they stand overall.
- Close by pointing at the next natural step in the phase (or the `start-phase` skill to continue the loop from there).
