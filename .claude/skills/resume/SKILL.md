# Resume

Re-entry ritual after a break, per the standing rule in `PROGRESS.md`: don't restart, re-enter. Momentum returns in an evening; guilt-driven restarts cost weeks.

## Procedure

1. **Read `PROGRESS.md`.** Identify:
   - the current phase: the first phase section with unchecked boxes;
   - the last logged retrieval checkpoint (the "Retrieval-checkpoint log" table: date, phases sampled, score, weak terms).
2. **Step 1 — retrieval first.** Offer to re-run that last retrieval checkpoint right now, using the `quiz` skill flow on the same phases it sampled, making sure the logged weak terms are included. If no checkpoint is logged yet, offer the current phase's quiz instead. If the learner declines, move on without comment.
3. **Step 2 — re-anchor.** Show the current phase's Objectives, verbatim, from `phases/phase-<n>-*/README.md`. No summary, no additions — the point is recognition, not novelty.
4. **Step 3 — three warm-ups.** Propose exactly three 30-minute tasks drawn from the phase's unchecked items, smallest first — the shape to aim for: a link or doc fix, a single test, a small PR. For each: what to do, where (file or README section), and what "done" looks like within 30 minutes. Ask which one to start with, and help do it.

## Tone rules

- Momentum, zero guilt. Never mention how long the break was, never tally lost time, never suggest redoing completed work.
- Do not audit the whole tracker or enumerate everything outstanding — that is the `gate-check` skill's job, offered only if the learner asks where they stand overall.
- Close by pointing at the next natural step in the phase (or the `start-phase` skill to continue the loop from there).
