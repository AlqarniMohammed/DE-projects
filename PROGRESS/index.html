    Progress Tracker¶

    Gates decide advancement — not the calendar. A phase is done when every item of its gate is covered with evidence linked here (repo, screenshot, video, score). Slipping weeks costs nothing; skipping gates costs everything.

    Work phases via the guide; this file is where evidence lands. The gate checklists live in each phase README — that is the single source of truth. Coming back after a break? Use the comeback ritual.

    Started: ____ · Target pace: 6–10 focused h/week (see the honest hour math) · Standing rules: listed once in the guide.

    How to log evidence (read once)¶

    • Videos: any screen recorder (OBS, Loom); host unlisted (YouTube/Drive); paste the link in the table. Voice memos: your phone is fine; note the date.
    • Retrieval checkpoints: a quiz of all the current phase's glossary terms + 10 random earlier terms, ≥80% to pass. Three ways to run it: the /quiz skill (does everything) · Anki custom study over your P0 deck (at import, suspend future phases' tags; unsuspend each phase as you reach it) · cover-the-definition straight from GLOSSARY.md. Log every run in the table at the bottom.
    • Notes and small artifacts (comparison paragraphs, concept notes) live in your platform repo under notes/, linked from the tables below.
